# Sons du jeu

Remplacez les trois fichiers MP3 vides ci-dessous par vos sons :

- `petting.mp3` — son joué quand on caresse une peluche.
- `button-click.mp3` — son joué au clic sur les boutons du jeu.
- `chest-open.mp3` — son joué lorsqu'un coffre s'ouvre.
- `background-music.mp3` — musique d'ambiance en boucle, lancée à la première interaction avec le jeu.

Les fichiers sont servis par `/api/sound/`. Les fichiers manquants ou vides
ne sont pas lus ; déposez les MP3 à cet emplacement puis actualisez le jeu.

Sons repérés sur Pixabay :

- [Impact and friction on a soft sheet](https://pixabay.com/sound-effects/household-impact-and-friction-on-a-soft-sheet-23313/)
- [Soft UI Click](https://pixabay.com/sound-effects/film-special-effects-soft-ui-click-147352/)
- [Chest Opening](https://pixabay.com/sound-effects/household-chest-opening-87569/)
